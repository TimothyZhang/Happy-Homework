# 产品文档索引

这个文件用于快速说明 `miniapp-starter` 项目里每份产品/方案文档各自负责什么。

## 文档列表

### 1. `V1-PRD-homework-pet.md`
**定位：** 小程序整体 V1 产品设计文档。

**覆盖内容：**
- 产品定位与目标用户
- 作业管理主链路
- 时间预估与排期
- 打卡奖励
- 电子宠物养成
- V2 社交能力预留

**适合什么时候看：**
- 想快速理解这个小程序整体想做什么
- 想看 V1 的核心功能边界
- 想看页面结构和产品范围

### 2. `V1-PRD-homework-register-ocr.md`
**定位：** 作业登记本 OCR 专项产品设计文档。

**覆盖内容：**
- 为什么要做整页作业识别
- 用户上传图片后的完整流程
- OCR 识别结果如何拆分成多条作业草稿
- 用户如何编辑确认并导入
- MVP 范围、异常处理与验收标准

**适合什么时候看：**
- 想推进 OCR 导入功能
- 想对齐产品和技术对“整页识别”的理解
- 想明确 V1 该做什么、不该做什么

### 3. `CLOUD-DATA-NOTES.md`
**定位：** 云开发数据结构草案。

**覆盖内容：**
- `users`
- `families`
- `children`
- `homeworkTasks`
- `coinLogs`
- `pets`
- `shopOrders`

**适合什么时候看：**
- 要开始把原型数据落到云数据库时
- 要讨论表结构和迁移顺序时

### 4. `CLOUD-SETUP.md`
**定位：** 微信云开发接入说明。

**覆盖内容：**
- 当前已经接好的调用链
- 哪一步还必须在微信开发者工具里完成
- 云函数部署说明
- 接真实 OCR 的替换点

**适合什么时候看：**
- 要继续推进 OCR 联调时
- 要查现在到底卡在哪一步时

## 推荐阅读顺序

如果是第一次接手这个项目，建议按下面顺序看：

1. `README.md`
2. `V1-PRD-homework-pet.md`
3. `V1-PRD-homework-register-ocr.md`
4. `CLOUD-DATA-NOTES.md`
5. `CLOUD-SETUP.md`
